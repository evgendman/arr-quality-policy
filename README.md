# arr-quality-policy

Единый источник принципов отбора релизов и конфигураций Quality Profiles / Custom Formats для Radarr и Sonarr.

## Цели проекта

- Зафиксировать общую политику оценки качества, источника релиза и озвучки.
- Хранить целевые конфигурации отдельно от фактических экспортов из приложений.
- Версионировать настройки и переносить их на выбранные экземпляры Arr с проверкой результата через API.
- Поддерживать необязательные наборы настроек — например, UHD/4K — без автоматического включения во всех экземплярах.

## Документация

- [Дорожная карта](docs/roadmap.md) — согласованные задачи, включая подготовку опциональных групп качества 4K для выбранных экземпляров Radarr и Sonarr.

## Область действия

Начальный этап: профили RU 1080p для Radarr и Sonarr. Варианты 4K/UHD и другие конфигурации должны подключаться отдельно, по выбору.

**Важно:** наличие правила или задачи в этом репозитории не означает, что оно уже применено к работающему приложению. Изменение считается выполненным после применения и проверки выгрузки через API.
