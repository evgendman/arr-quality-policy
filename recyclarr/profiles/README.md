# Quality Profile templates

В каталоге находятся Recyclarr include-фрагменты, отражающие текущие профили 1080p:

- [Radarr 1080p RU](radarr-1080p-ru.yml)
- [Sonarr 1080p RU](sonarr-1080p-ru.yml)

## Подключение

Файлы содержат только блок уровня экземпляра (`quality_profiles`), как требует Recyclarr для локальных YAML includes. Они не являются самостоятельными корневыми конфигурациями.

Чтобы подключить шаблон к конкретному экземпляру, добавьте `include` внутрь его блока в основном Recyclarr YAML:

```yaml
radarr:
  mini_radarr_4k:
    include:
      - config: /opt/arr-quality-policy/recyclarr/profiles/radarr-1080p-ru.yml
```

Для Sonarr используется аналогичный путь к `sonarr-1080p-ru.yml`. Путь выше предполагает, что репозиторий размещён в `/opt/arr-quality-policy`; при другом размещении его нужно изменить. Recyclarr разбирает includes относительно своего каталога конфигурации, поэтому абсолютный путь здесь выбран намеренно.

Эти шаблоны пока **не подключены** к текущим `recyclarr/config/radarr.yml` и `recyclarr/config/sonarr.yml`: обычный Sync продолжает управлять только Custom Formats. Это сохраняет разделение между сохранёнными эталонами профилей и включением управления Quality Profile по отдельному решению.

## Повторное использование для 4K

Для нового экземпляра можно использовать соответствующий фрагмент как основу. Перед применением нужно задать имя нового профиля и изменить `upgrade.until_quality` на целевую 2160p-группу/качество, а также включить нужные элементы 2160p.

Текущая структура сохранена без искусственного объединения разных качеств:
- Radarr: отдельная группа `4K`, сейчас отключена целиком.
- Sonarr: группа `WEB 2160p` и отдельные `HDTV-2160p`, `Bluray-2160p`, `Bluray-2160p Remux`; все сейчас отключены.

## Ограничение Recyclarr

В Recyclarr 8.8.1 `enabled` задаётся для элемента верхнего уровня. Для группы этот флаг распространяется на все вложенные качества; индивидуальный `enabled` для члена группы схема YAML не допускает.

В живом профиле Radarr группа `SD` разрешена, но её `WEBDL-480p` и `WEBRip-480p` отдельно запрещены. Чтобы не включить их случайно при будущем Sync, в `radarr-1080p-ru.yml` они представлены отдельными отключёнными пунктами сразу после группы `SD`. Это единственное структурное отличие Recyclarr-фрагмента от фактического дерева Radarr; остальные группы и статусы отражены по сохранённым данным профилей.

## Параметры профилей

Оба шаблона фиксируют:
- `upgrade.allowed: true`;
- cutoff по группе `1080p`;
- `until_score: 0`;
- `min_format_score: 0`;
- `min_upgrade_format_score: 1`;
- полный упорядоченный перечень используемых качеств и групп, включая отключённые 2160p-элементы.

`quality_sort: top` указан явно: перечисленные группы и качества сохраняют порядок.
