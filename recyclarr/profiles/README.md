# Quality Profile templates

В каталоге находятся Recyclarr include-фрагменты для профилей Radarr и Sonarr:

- [Radarr 1080p RU](radarr-1080p-ru.yml)
- [Sonarr 1080p RU](sonarr-1080p-ru.yml)

Оба шаблона содержат полный сервисный набор используемых качеств и групп, включая варианты 2160p. Отличаются только реальные возможности и названия групп конкретного приложения.

## Порядок групп качества

**Во всех универсальных шаблонах порядок групп фиксирован сверху вниз: 4K → 1080p → 720p → SD.**

Это не косметическое расположение. Верхняя группа задаёт наивысшую ступень Quality Profile и влияет на логику выбора целевого качества и cutoff. Параметр `quality_sort: top` указан явно; порядок в YAML следует сохранять именно таким. Не переставляйте SD выше 4K.

Для Radarr группа называется `4K` и включает Remux-2160p, WEBRip-2160p, HDTV-2160p, Bluray-2160p и WEBDL-2160p.

Для Sonarr группа называется `4К` (кириллическая «К») и включает HDTV-2160p, WEBRip-2160p и WEBDL-2160p. Bluray-2160p и Bluray-2160p Remux в Sonarr остаются отдельными качествами — это сервисное отличие, его нельзя искусственно устранять.

## Подключение

Файлы содержат только блок уровня экземпляра (`quality_profiles`), как требует Recyclarr для локальных YAML includes. Они не являются самостоятельными корневыми конфигурациями.

Чтобы подключить шаблон к конкретному экземпляру, добавьте `include` внутрь его блока в основном Recyclarr YAML:

```yaml
radarr:
  mini_radarr_4k:
    include:
      - config: /opt/arr-quality-policy/recyclarr/profiles/radarr-1080p-ru.yml
```

Для Sonarr используется аналогичный путь к `sonarr-1080p-ru.yml`. Путь выше предполагает, что репозиторий размещён в `/opt/arr-quality-policy`; при другом расположении его нужно изменить. Recyclarr разбирает includes относительно своего каталога конфигурации, поэтому абсолютный путь здесь выбран намеренно.

Эти шаблоны не подключены к активным `recyclarr/config/radarr.yml` и `recyclarr/config/sonarr.yml`: текущие постоянные Sync-конфигурации управляют Custom Formats и их оценками отдельно от ручного выбора групп качества.

## Повторное использование для 4K

Для нового 4K-профиля используйте тот же полный список качеств и групп — отдельный JSON-каталог качества не нужен. Измените имя профиля и cutoff на целевую группу (`4K` для Radarr, `4К` для Sonarr). При первоначальном Sync группа cutoff не должна быть явно отключена: включите её в YAML, чтобы Recyclarr принял cutoff. После первоначального создания профиля пользователь может изменить флажки групп и cutoff в интерфейсе Arr.

## Первоначальное создание и последующие Sync

Recyclarr применяет `quality_profiles.qualities` как описание дерева качеств. Если этот блок оставить в регулярном Sync, Recyclarr будет продолжать управлять составом и состоянием групп, поэтому ручные изменения флажков пользователя могут быть перезаписаны.

Практическая схема:
1. На этапе первоначального создания выполнить Preview и Sync с полным блоком `quality_profiles` и `qualities`.
2. Проверить группы, состав качеств и cutoff через интерфейс/API Arr.
3. После того как профиль создан, убрать из постоянной конфигурации блок `qualities` и блок `upgrade`, если группы, их флажки, Upgrade Allowed и cutoff должны оставаться под управлением пользователя.
4. Оставить в постоянной конфигурации `min_format_score`, `min_upgrade_format_score` и назначения `custom_formats.assign_scores_to`. Тогда повторный Sync обновляет веса, но не изменяет выбранные пользователем группы и cutoff.

## Ограничение Recyclarr

В Recyclarr 8.8.1 `enabled` задаётся для элемента верхнего уровня. Для группы этот флаг распространяется на все вложенные качества; индивидуальный `enabled` для члена группы схема YAML не допускает.

В живом профиле Radarr группа `SD` разрешена, но её `WEBDL-480p` и `WEBRip-480p` отдельно запрещены. Чтобы не включить их случайно при первоначальном Sync, в `radarr-1080p-ru.yml` они представлены отдельными отключёнными пунктами сразу после группы `SD`.

## Параметры 1080p-шаблонов

Оба текущих шаблона фиксируют:
- `upgrade.allowed: true`;
- cutoff по группе `1080p`;
- `until_score: 0`;
- `min_format_score: 0`;
- `min_upgrade_format_score: 1`;
- полный набор качеств и групп, упорядоченный от 4K к SD.
